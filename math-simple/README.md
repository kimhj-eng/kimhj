# 같이 생각하기 (간소화 버전)

답 대신 다음 생각을 물어보는 초등 수학 학습 도우미.

**필요한 것은 Anthropic API 키 하나뿐입니다.** 로그인도, 데이터베이스도 없습니다.
기록은 그 기기의 브라우저 안에만 남습니다.

```
public/                 브라우저에 내려가는 것 (키가 없다)
netlify/functions/      서버. API 키와 힌트 규칙이 여기에만 있다
```

---

## 설치 (5분)

### 1. GitHub에 올리기

이 폴더를 GitHub 저장소에 올립니다. `kimhj-eng` 계정을 쓰시면 됩니다.

> **드래그 배포는 쓰지 마세요.** 서버 함수가 올라가지 않아 문제 풀이가 되지 않습니다.
> 반드시 저장소를 연결하는 방식이어야 합니다.

### 2. Netlify 연결

Netlify → **Add new site → Import an existing project** → 그 저장소 선택.
빌드 설정은 `netlify.toml` 에 들어 있으니 그대로 두고 배포하시면 됩니다.

### 3. 환경변수 등록

**Site configuration → Environment variables**

| 이름 | 값 | 필수 |
|---|---|---|
| `ANTHROPIC_API_KEY` | Anthropic 콘솔에서 발급한 키 | ✅ |
| `PASSCODE` | 접속 암호 (아무 문자열) | 선택 |

등록 후 **Deploys → Trigger deploy → Deploy site** 로 재배포해야 반영됩니다.

`PASSCODE` 를 설정하지 않으면 주소를 아는 사람은 누구나 쓸 수 있습니다.
**키 비용이 운영자 부담이므로 반드시 설정하시길 권합니다.**
설정한 뒤에는 첫 화면에서 그 암호를 입력해야 들어옵니다.

### 4. 확인

사이트를 열고 암호를 넣은 뒤 "들어가기"를 누릅니다.
이때 서버로 시험 호출이 한 번 나가므로, 여기서 통과하면 나머지도 다 됩니다.

오류가 나면 그 문구가 원인을 그대로 알려줍니다.

| 문구 | 원인 |
|---|---|
| 서버 기능을 찾지 못했습니다 | 드래그 배포로 올렸습니다. 저장소 연결로 바꾸세요 |
| 암호가 맞지 않습니다 | `PASSCODE` 와 입력값이 다릅니다 |
| ANTHROPIC_API_KEY 가 설정되지 않았습니다 | 환경변수 등록 후 재배포하지 않았습니다 |

## 쓰는 법

**아이**는 사진을 찍거나 문제를 적고, 힌트를 받아 가며 생각을 이어 갑니다.
답을 알려달라고 해도 알려주지 않습니다.

**선생님·보호자**는 두 가지를 볼 수 있습니다.

- 우측 상단 **교사 보기** — 각 힌트 아래에 강도(H값), 방향 판정, 막힘 유형이 나타납니다
- **지난 기록 보기** — 푼 문제 목록, 대화 전문, 그리고 일주일치를 묶은 서술형 리포트

리포트에는 숫자가 나오지 않습니다. 점수가 아니라 아이가 어디서 멈췄고
어떻게 다시 걸었는지를 이야기로 전합니다.

## 동작 방식

### API 키는 어디에 있나

브라우저는 Anthropic을 직접 부르지 않습니다.

```
브라우저 ──> Netlify Function ──(ANTHROPIC_API_KEY)──> Anthropic
```

키는 Netlify 환경변수에만 있고 브라우저로 내려가지 않습니다.

### 힌트 강도는 서버가 정한다

강도 규칙이 브라우저에 있으면 아이가 개발자 도구로 바꿀 수 있습니다.
`_lib.mjs` 의 `nextStrength()` 가 유일한 결정권자입니다.

```
correct → +2   잘 따라오는 아이를 붙잡아 두지 않는다
wrong   → +1
unclear → H0   문제 이해부터 다시
새 개념  → H1
답 요청  → 유지 (조른다고 올라가지 않는다)
```

강도는 사다리가 아니라 도구 상자입니다. H1에서 H3으로 뛰거나 H0으로 내려갑니다.

### 정답 노출 필터

프롬프트만으로는 정답 차단을 보장할 수 없습니다.
문제에 나온 수들로 만들 수 있는 사칙연산 결과 중 원래 없던 값을 뽑아 두고,
응답에 그 값이 나타나면 한 번 다시 생성합니다. 두 번째도 새면 안전 문구로 바꿉니다.

교사 보기를 켜면 필터가 작동한 턴에 `필터 작동` 이라고 표시됩니다.

## 알아 두실 것

**기록은 기기 안에만 있습니다.** 브라우저 데이터를 지우거나 기기를 바꾸면 사라집니다.
여러 기기에서 보셔야 하면 Supabase 버전으로 옮겨야 합니다.

**비용은 운영자 부담입니다.** `PASSCODE` 를 꼭 설정하시고,
Anthropic 콘솔에서 사용량 알림을 걸어 두세요.

**튜닝 1순위** 는 `nextStrength()` 의 `correct → +2` 입니다.
3학년 기준으로 잡았습니다. 아이가 벅차 보이면 `+1` 로 낮추세요.
